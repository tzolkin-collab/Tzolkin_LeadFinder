# Diretrizes do Projeto Lead Finder / Tzolkin

## 📲 Links de WhatsApp (Regra Obrigatória)
- **Todos os links de WhatsApp devem utilizar EXCLUSIVAMENTE a estrutura `https://wa.me/<numero>`** (formato E.164 sanitizado, ex: `https://wa.me/551933810001`).
- Nunca utilizar variações como `api.whatsapp.com` ou `web.whatsapp.com` nos links gerados para o usuário.
